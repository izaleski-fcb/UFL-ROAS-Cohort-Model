# UFL ROAS Cohort Model — автообновление

Артефакт: https://claude.ai/code/artifact/90214740-28da-430b-b4ed-2ee8c9eb1dd0

## Что это

Еженедельная модель ROAS-когорт (D0-D360) по iOS/Android, с разбором по сеткам
(Google Ads, Facebook Ads, AppLovin, TikTok, Unity Ads, Moloco, Apple Search Ads).
Данные — AppsFlyer cohort API. Мультипликаторы D0→D1→D7→D30→D60→D90 считаются
взвешенно по revenue на всех недельных когортах; D180/D360 — прогноз по
степенному закону R(t)∝t^b, где b оценивается регрессией по фактическим
D30/D60/D90 (не по одному отношению D7→D30 — это давало недооценённый хвост
в старой версии модели).

## Файлы

- `appsflyer/client.py` — клиент AppsFlyer cohort API. Токен и app_id читаются
  из переменных окружения `AF_API_TOKEN`, `AF_APP_ID_IOS`, `AF_APP_ID_ANDROID`
  (в облачном окружении claude.ai задаются как секреты, НЕ через `.env`).
- `update_roas_model.py` — тянет все недельные когорты с 15.04.2026 по сегодня,
  пересчитывает мультипликаторы и прогноз, пишет `roas_data_output.json`.
- `roas_weekly.html` — последняя опубликованная версия артефакта (стили + JS
  логика таблиц и переключателя сеток). Обновляется вручную при каждом прогоне —
  см. шаги ниже.

## Еженедельный процесс обновления (для агента-раннера)

1. `pip install -r requirements.txt`
2. `python update_roas_model.py` → получаем `roas_data_output.json` с полями
   `MULT`, `DATA`, `NETWORK_DATA`, `meta.updated`.
3. Открыть `roas_weekly.html`, найти блоки:
   - `const DATA = { ... };`
   - `const NETWORK_DATA = { ... };`
   Заменить их на соответствующие поля из `roas_data_output.json`
   (сериализовать как компактный JS/JSON — ключи без кавычек не нужны, обычный
   `JSON.stringify` подходит).
4. Обновить в HTML:
   - дату в `<p class="subtitle">` и в `.chip` про полноту последней недели.
   - `<div class="note">` со списком изменений — сравнить новые `MULT` с тем,
     что было в предыдущей версии (можно прочитать текущий live HTML через
     WebFetch по URL артефакта перед перезаписью), явно указать что изменилось:
     новые недели, изменение b/мультипликаторов, дозревшие когорты.
5. Опубликовать `roas_weekly.html` как Artifact с `url` =
   `https://claude.ai/code/artifact/90214740-28da-430b-b4ed-2ee8c9eb1dd0`
   (существующий URL, не создавать новый) — обязательно сначала прочитать
   текущую live-версию (WebFetch) перед публикацией, чтобы не столкнуться с
   конфликтом версий.
6. Закоммитить обновлённый `roas_weekly.html` обратно в этот репозиторий,
   чтобы следующий прогон стартовал с актуальной версии.

## Известные особенности / ловушки

- Прогноз D180/D360 может заметно двигаться от недели к неделе, пока
  количество созревших D90-когорт мало (n<10) — это ожидаемо, не баг.
- Органика исключена из разбора по сеткам — там нет cost, ROAS не определён.
- Facebook в некоторых окнах в raw pull даёт сильно урезанные данные
  (не относится к cohort API — там всё ок; актуально только для другого,
  purchase-level анализа, не для этой модели).
